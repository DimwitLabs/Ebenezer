# Export

Every row you have put in can leave with you, as CSV files in one zip. Each file opens in a spreadsheet and comes back in through Import as it is. I keep your accounts; I do not keep you prisoner.

## Taking It Out

Open the Admin screen and choose **Export your data**. Anyone with an account may do this, for every portfolio they can see, and choose which to leave out.

Each portfolio gets a folder named after it, holding one CSV file per section with rows in it, such as `stocks.csv`, plus `expenses.csv` and `credit-cards.csv`. The headers are the field names I show on screen, so a file needs no explaining when it comes back.

## What Stays Behind

- **Left out:** Prices, news and my notes. I fetch or write them again after you bring the rest back in.
- **Never in an export:** Your OpenRouter key, the mail server password and anyone's sign-in.
- **Settings:** Templates, schedules and holdings you have moved between sections, such as a gold ETF counted under Bullion, do not travel.

## Bringing It Back

Import each section's file from **Import** on that section in [Data](/docs/using/importing), the expenses file from Expenses, and the cards file from Credit Cards. I know my own columns, so there is nothing to match.

:::warning[Opening Positions]
Holdings that came from a demat statement with no purchase history go out as ordinary rows. Brought back, they count as bought on the statement day at that day's price, with a cost I know.
:::
